# turbo-expander

Текущая рабочая версия `turbo-expander-v2` для MMA: компрессор и турбодетандер на общем валу, две независимые P–P гидравлические цепи и динамика ротора.

## Что находится в репозитории

- `src/del/devices` — устройства `gpaTurboExpander` и `gpaTurboExpanderV2`;
- `src/del/elements` — уравнения аппарата и гидравлические корреляции;
- `src/del/infos` — описание параметров, портов и сенсоров;
- `Tests/perm-devices/turbo-expander-v2` — дымовые, номинальные, паспортные и сигнальные P–P сценарии;
- `headless` — отдельная сборка библиотеки, запуск теста с кэшированной библиотекой и выгрузка сенсоров;
- `docs/validation-status.md` — фактически проверенное состояние, известные ограничения и рекомендации.

## Быстрый запуск

Репозиторий рассчитан на размещение в корне MMA рядом с `del_new2` и `lib_tester_new`: скрипты используют эти каталоги как исходники и тестировщик соответственно.

```bash
cd /path/to/MMA/tda
./headless/build-turbo-expander-v2.sh
./headless/run-turbo-expander-v2.sh \
  Tests/perm-devices/turbo-expander-v2/passport-regime-100-p-p
```

Для примера пуска с нулевой частоты и ступенчатой уставкой клапана:

```bash
./headless/run-turbo-expander-v2.sh \
  Tests/perm-devices/turbo-expander-v2/passport-regime-100-p-p-startup
```

Сначала всегда выполняется сборка; дальнейшая правка только XML/Excel-сигналов не требует пересборки — используется `headless/cache/turbo-expander-v2/libperm-devices.so`.

## Принятые допущения

Клапаны заданы номинальным местным сопротивлением, площадью прохода и фактической степенью открытия. Их открытие — динамическая переменная первого порядка, уставка подаётся из Excel-сигнала.

Давления на всех четырёх внешних границах заданы явно (P–P). В паспортном варианте вход и выход компрессора имеют одинаковое внешнее давление `2 595 кПа`; внутренний клапан забирает паспортный напор компрессора. Это осознанная стендовая постановка, а не описание замкнутого контура с объёмом газа.

В потоковую энтальпию пока передаётся постоянное паспортное изменение энтальпии; расчёт по `Cp`, `k`, `η` сохранён как диагностический. Полное описание ограничений и рекомендуемый путь развития приведены в [docs/validation-status.md](docs/validation-status.md).
