# turbo-expander

Модель `turbo-expander-v2` для проекта MMA с компрессором и турбодетандером на общем валу.

## Содержимое

- `src/del/devices` — устройства `gpaTurboExpander` и `gpaTurboExpanderV2`;
- `src/del/elements` — элемент, математические зависимости и совместимый старый элемент;
- `src/del/infos` — описания устройств;
- `Tests/perm-devices/turbo-expander-v2` — P–P тесты, Excel-сигналы клапанов и варианты режимов;
- `headless` — сборка, запуск и выгрузка сенсоров.

Клапаны описываются номинальным местным сопротивлением, площадью прохода и фактической степенью открытия. Степень открытия является динамической переменной первого порядка и получает уставку из сигнала теста.

Энергетическая связь содержит фиксированные номинальные приращения энтальпии и отдельные сенсоры формульного расчёта и отклонения от констант.
