# Пуск паспортного режима 100: P–P и ступени клапана

Сценарий воспроизводит паспортные граничные условия режима 100 и запускает общий вал с нулевой частоты.

- ТДС: `7 990 → 2 944 кПа`;
- КС: `2 595 → 2 595 кПа` — номинальный напор компрессора поглощается его внутренним клапаном;
- начальная частота: `0 об/мин`;
- инерционность каждого клапана: `2 с`;
- `test.xlsx`: открытие клапана турбины `0`, `0.1`, `0.5`, `1.0` полками по 50 с.

Составы и температуры взяты из паспорта режима 100. Молекулярные массы, восстановленные по долям: ТДС `18.03171 кг/кмоль`, КС `16.22596 кг/кмоль`, что соответствует паспортным `18.03` и `16.23`.

Сценарий диагностический: переход `0 → 0.1` сейчас выявляет жёсткость гидравлического уравнения закрытого клапана. Подробность и рекомендуемая правка описаны в [`docs/validation-status.md`](../../../../docs/validation-status.md).
