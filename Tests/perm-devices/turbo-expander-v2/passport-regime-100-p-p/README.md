# Паспортный режим 100: P-P

Граничные условия обоих контуров заданы давлением: ТДС `7 990 → 2 944 кПа`, КС `2 595 → 3 336 кПа`.
Входные температуры и составы взяты из `G1-22X01_ОЛ.pdf` и `ОЛ ТДА.xlsx`.

Состав ТДС содержит все паспортные компоненты; его молекулярная масса по долям равна `18.03171 кг/кмоль`, что совпадает с паспортными `18.03`.
Состав КС даёт `16.22596 кг/кмоль`, что совпадает со строкой условий `16.23`. Итог `17.95` в таблице состава паспорта противоречит её собственным долям и не используется.

Для устранения вырождения P-P постановки у компрессора введено минимальное внутреннее сопротивление `ζ = 0.01`. Напор увеличен с `741` до `748.41 кПа`, поэтому при номинальном расходе внешний перепад остаётся паспортным `741 кПа`.

Выходные температуры сохранены как паспортные граничные данные. Они не являются эталонами модели, пока в `turbo-expander-v2` нет тепловой/энтальпийной модели потока.
